## 3. Fonctionnalités

Dans ce jeu il y a plein de fonctionnalités que je vais vous expliquer tel que

- Les images sont générées aléatoirement par une API qui nous a été donnée (https://picsum.photos)

- Le mélange des paires de cartes utilise l'algorithme de Fisher-Yates qui est utilisé dans shuffle

- Le système de retournement de cartes est géré par des clics et à la fonction lockBoard qui empêche de pouvoir cliquer sur une troisième carte lors des sélections

- La détection de paires est gérée par dataset.values et check qui compare les valeurs des images pour voir si elles sont identiques et les laisser retournées

- Le Chronomètre commence dès qu'on appuie sur le bouton "Jouer" et est formaté en mm:ss

- Le compteur de coups s'incrémente à chaque essai de paires de cartes  

## 4. Lancement en local

Si vous avez téléchargé mon site je vous en remercie dans un premier temps. Ensuite voilà comment le lancer :

- Téléchargez le dossier zippé depuis GitHub

- Décompressez le fichier

- Double-cliquez sur le fichier index.html

- Appuyez sur le bouton "jouer" et voilà bonne chance et **QUE LA MEILLEURE MÉMOIRE GAGNE !!**
